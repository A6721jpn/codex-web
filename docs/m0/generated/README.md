# Generated App-Server Protocol Snapshots

This directory contains generated TypeScript and JSON Schema snapshots from `codex app-server`.

Do not read these files as narrative documentation. They are useful when validating protocol types, checking schema drift, or updating the app-server compatibility gate.

For human or LLM orientation, start with:

- `docs/agent-reading-guide.md`
- `docs/architecture/overview.md`
- `docs/m0/protocol-and-windows-feasibility.md`

Regenerate with:

```powershell
npm run m0:generate-protocol
```
